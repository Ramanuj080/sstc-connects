Create a premium, modern student social platform called **SSTC Connect** for **Shri Shankaracharya Technical Campus (SSTC), Bhilai**.

### CORE IDEA

SSTC Connect is a **digital campus and student community platform** where students can:

* Discover and share notes
* Find highly specific academic resources
* Ask and answer questions
* Learn from seniors
* Discuss subjects and campus life
* Share projects, opportunities and events
* Discover useful study materials
* Sell premium notes and study packs using campus points
* Use an AI-powered campus assistant

This should NOT feel like a basic notes website or a generic college portal.

It should feel like:

**A social network + academic library + student community + knowledge marketplace + AI assistant**

built specifically for SSTC students.

The goal is to create a website that feels like a **real startup product**, not a college project.

# VISUAL STYLE

The website should have a distinctive **Indian heritage academic aesthetic combined with modern technology**.

The visual inspiration should come from:

* Old Indian libraries
* Academic manuscripts
* Traditional architecture
* Parchment/paper textures
* Classical academic institutions

But the interface itself must feel like a **modern 2026 social platform**.

Think:

**Indian heritage × Modern social media × Premium technology**

Color palette:

* Deep maroon
* Dark brown
* Warm cream
* Muted saffron
* Subtle antique gold
* Charcoal

Use elegant serif fonts for major headings and modern sans-serif fonts for UI.

Use subtle traditional patterns and ornamental details.

IMPORTANT:

Do not make it look overly religious, ancient, or like a museum.

It should feel **young, premium, aesthetic and technologically advanced**.

**"What if SSTC had its own combination of Reddit + Notion + LinkedIn + Google Drive + an AI assistant?"**

Populate the prototype with realistic fictional students, resources, discussions, notes, profiles and activity so the website feels alive immediately.
